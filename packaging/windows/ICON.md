# Icono de HidroCAUMAX

Creado para el instalador de Windows mediante la herramienta integrada de generación de imágenes. El río en crecida, el relieve de la cuenca y una curva de avenida identifican el propósito hidrológico del programa. No se ha reutilizado el icono de otra aplicación.

- `hidrocaumax.png`: PNG de 512 × 512, con transparencia.
- `hidrocaumax.ico`: icono de Windows con tamaños 16, 24, 32, 48, 64, 128 y 256 píxeles.

La adaptación posterior se limita a conversión de formato y resolución para Windows.

## Descripción utilizada

Use case: logo-brand. Asset type: Windows installer and desktop application icon for Spanish hydrology software HidroCAUMAX, in the visual family of polished hydrometeorological software icons. Create a single square icon with transparent outside corners: a beautifully simple rounded square cobalt-blue and deep navy badge containing a bold luminous cyan river flood crest flowing through a stylized green-blue watershed valley. The foreground water is visibly high and rising, with two clean white-cyan foam streaks and one subtle peak shape suggesting a flood hydrograph. The image should read as river flood hydrology, not an ocean surfing logo. Crisp professional enamel-like surfaces, restrained depth and highlights, confident large silhouettes that remain legible at 32x32 pixels. Centered composition filling 88 percent of canvas with safe transparent margins. No small scenic detail, no houses, no people, no text, no letters, no logo from another brand, no watermark. This is a production application icon, not a scene illustration. Transparent background outside the badge.
